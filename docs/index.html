// Core Systems

Built from scratch. Zero legacy C.

Every subsystem rewritten in idiomatic Rust — from BSP parsing to PBR rendering.

⚙

wgpu HDR Renderer

Rgba16Float scene buffer, ACES tonemapping, multi-mip bloom, SSAO, cascaded shadow maps (PCF 3×3), TAA, SSR water, god rays, volumetric fog.

⚔

PBR Cook-Torrance

GGX NDF + Smith geometry + Schlick Fresnel. Normal maps via cotangent frame (Mikkelsen). Metallic/roughness from glTF materials.

🤖

Physics Bot Animations

Ragdoll death, hit-reaction springs, look-at IK, torso lag, strafe blending, and terrain surface alignment. All on MD3's 3-piece model system.

🛠

In-Game Level Editor

Free mouse cursor, side panel UI, native file dialog for GLB import. Spawn, select, move, scale, rotate, align to terrain. JSON save/load.

🌎

Battle Royale: Reunion

Procedural terrain, POI tiers, optional ring shrink. 1,800 procedural grass tufts + 1,200 icosahedron rocks. Terrain-aligned props.

🔒

Server Anti-Cheat

720°/s angular cap, teleport detection, dt budget, lag-comp 250ms max rewind, saturating arithmetic, magic file check on downloads.
